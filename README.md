# Monitoring-Wind-Turbine-System
Designed and developed an IoT-enabled wind turbine monitoring system for real-time measurement and analysis of power and energy generation. Implemented a custom hardware setup using sensors, ESP8266, and a PCB-based circuit assembled on a universal board. Integrated cloud platforms including ThingSpeak, Blynk, and web dashboards for remote monitoring, visualization, and performance analysis of renewable energy data.

Key Contributions:

- Designed and assembled a custom PCB-based monitoring circuit on a universal board.
- Integrated sensors and ESP8266 for real-time data acquisition and wireless communication.
- Developed cloud-based dashboards using ThingSpeak and Blynk for remote monitoring.
- Measured and analyzed wind turbine power and energy generation data.
- Applied IoT concepts for renewable energy monitoring and smart energy management.
